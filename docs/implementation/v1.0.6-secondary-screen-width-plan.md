# Jig v1.0.6 secondary-screen width implementation plan

**Status:** Binding implementation plan.  
**Target release:** v1.0.6 patch.  
**Functional authority:** `docs/requirements/planning-workbench.md` JIG-106-FR-01.  
**Technical authority:** `docs/architecture/technical-solution.md` JIG-106-SD-01.  
**UI authority:** `docs/design/ui-solution.md` v0.16.

## Problem

Published v1.0.5 correctly made the application frame full-bleed, but History and Settings inherited the entire desktop canvas width. Those two secondary reading/configuration surfaces become unnecessarily stretched on wide displays. Planner is different: its seven-track desktop board intentionally consumes the full available canvas and must remain unconstrained.

## J106-IMP-01 — Bound desktop History and Settings content

**Closes:** JIG-106-FR-01 / JIG-106-SD-01.

**Primary files**
- `ui/src/styles.css`
- `tests/architecture/ui-ownership.test.ts`
- `tests/browser/ui-conformance.spec.ts`

**Required implementation**
1. Keep AppShell, header, content frame and generic content full-bleed with zero viewport inset.
2. Keep Planner's week board unconstrained.
3. At desktop composition, set `.jig-history-view` and `.jig-settings-view` to `width: 100%`, `max-width: 50rem`, `margin-inline: auto`.
4. Below the existing 73rem breakpoint, restore the two secondary screens to full available width and zero inline margin.
5. Replace the Settings fixed `560px / 580px` grid with two equal fluid `minmax(0, 1fr)` columns. Preserve the existing single-column narrow layout.
6. Do not add a wrapper, component state, another breakpoint, a layout mode branch, DTO/ViewModel, service/repository abstraction or private Astryx override.

**Verification**
- 1440px desktop: History width ~800px, x ~320px.
- 1440px desktop: Settings width ~800px, x ~320px.
- 1440px desktop: Planner remains ~1440px wide and x=0.
- 390px narrow: History and Settings each render ~390px wide and x=0.
- Architecture test rejects the previous fixed Settings columns and confirms the one 50rem owner.
- Permanent Verify passes.
