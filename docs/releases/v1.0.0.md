# Jig 1.0.0 — release notes draft

**Status:** Prepared release notes for the first stable Jig release.  
**Target tag:** `v1.0.0`

Jig 1.0.0 is the first stable release of the local-first just-in-time daily planner.

## What it does

Jig gives one person a lightweight dated plan across projects and obligations without duplicating the project systems that own the real work.

- Plan and reorder work in a seven-day Week view.
- Focus on one Day while earlier unfinished work remains visibly carried over.
- Complete, reopen and permanently delete the same canonical Task identity.
- Keep optional priority, context, references, notes and reminders without workflow ceremony.
- Use pointer drag or non-drag movement with the same exact ordering semantics.
- Review completed work in History.
- Use System, Light or Dark appearance with responsive narrow-screen composition.

## Local-first persistence and synchronization

Successful edits commit immediately to SQLite under the selected planning repository. Jig exports deterministic portable Task records to an isolated `jig-data` ref/worktree and synchronizes them in the background when a Git remote is configured.

Repository transport failures never roll back a successful local Task save. Git history, merges and conflict reconciliation remain outside Jig and stay with ordinary Git tooling.

## Linux desktop lifecycle

The supported v1 release provides:

- Linux x64 and arm64 release bundles;
- pinned Bun 1.4.4 runtime inside each bundle;
- one bootstrap installer;
- existing-repository and clone installation modes;
- `jig` launcher;
- `systemd --user` service where available;
- foreground fallback;
- `jig status`, `jig sync`, `jig doctor`, repository migration and uninstall.

Uninstall removes Jig runtime/configuration while preserving the selected repository's `.jig` planning data by default.

## Deliberate v1 boundaries

Jig 1.0.0 is Linux desktop software. Independent phone installation, push notifications, collaboration, project-management workflows, automatic prioritization, time tracking, recurring tasks and Git reconciliation UI are outside this release.

## Installation

Use the latest stable release bootstrap:

```bash
curl -fsSL https://github.com/pontivus-com/jig/releases/latest/download/jig-install.sh \
  | bash -s -- --repo /absolute/path/to/your/planning-repo
```

See [installation](../install.md) for all supported modes and operational details.
