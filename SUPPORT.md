# Support

Jig is an open-source project maintained on a best-effort basis. There is no service-level agreement or guaranteed response time.

## Supported release

Use the latest stable release before reporting a correctness problem unless the issue is specifically an upgrade regression.

## Where to ask

| Question | Channel |
| --- | --- |
| Bug report | [GitHub issues](https://github.com/pontivus-com/jig/issues) |
| Feature request | [GitHub issues](https://github.com/pontivus-com/jig/issues) |
| Usage/install question | [GitHub issues](https://github.com/pontivus-com/jig/issues) |
| Security vulnerability | [Private report](SECURITY.md) |
| Release history | [CHANGELOG.md](CHANGELOG.md) |

## Useful report information

Include:

- Jig version;
- Linux distribution and CPU architecture;
- installation mode (existing repository or cloned repository);
- whether a remote is configured;
- output of `jig status` and relevant sanitized `jig doctor` fields;
- a minimal reproduction.

Do not paste credentials, private repository material or personal Task content.
